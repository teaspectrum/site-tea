Key points

  • Steeping time is one adjustable variable in brewing, but it never acts alone. Leaf dose, water temperature, time, water quality and vessel constrain one another; pushing one to the limit usually costs another.
  • Separate concept, variables and setting before copying a parameter.
  • With mould, sourness, clumping or unknown source, prioritise food safety.

Context

This page places Steeping time inside the framework of 冲泡方法: what problem it solves, which variables matter, and how to judge the result.

The short answer

The goal is not “maximum intensity” but a stable state: stop the changes that should stop and keep the aroma and structure worth keeping. Too much and too little both show up in the next brew.

What to watch

Judge with dry leaf, liquor, aroma, taste and infused leaf together. One handsome metric does not prove balance, and the same parameter does not suit every leaf grade or tea type.

A workable order

Check the raw material first, set one main variable second, record the result third, and compare it with the next infusion. If the result is poor, return to the variable table before blaming the tea.

Common misreadings

  • “Heavier is always more aromatic”: Over-roasting, over-rolling or over-fermentation more often brings char, stewed notes or emptiness.
  • “One number fits every tea”: Leaf grade, shape and tea type change the response to the same temperature and time.

Practical advice

Fix water, vessel and leaf amount; change one variable; record grams, millilitres, temperature, time and result; judge after three repeats. Discard tea with mould, sourness or clumping.

Source boundary

This page can establish the position of Steeping time in the chain and the variables that change its result. It cannot prescribe one fixed parameter for every batch or predict the cup from appearance alone.
