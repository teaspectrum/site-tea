菲律宾没有成规模的商业茶园；茶散在吕宋北部高山的小农地块与试验站，日常消费则被进口茶包、奶茶与即饮茶主导。

先看结论

菲律宾茶业是“小规模、分散、以试验与小农为主”。茶在 1905 年前引入，曾在 Baguio 与 Benguet 零星种植；Cordillera 高地有本土茶树与小型加工，但没有全国性庄园。2023 年起政府、大学与商界推动 Cordillera 茶园，Benguet State University 做可行性研究。读菲律宾，要把“潜力”与“现状”分开。

地理与产茶条件

Cordillera 高地海拔 1,300–2,000 米，气候凉爽、云雾多、土壤酸性，适合 Camellia sinensis var. sinensis。Sagada、Benguet、Mountain Province 是代表高地；坡地多、台风与暴雨、交通不便。低地炎热，适合咖啡、椰子与水果，不适合茶。

历史与产业

茶在 1905 年前引入，Baguio 与 Benguet 有零星种植；西班牙/美国时期以咖啡、柑橘与蔬菜为主，茶未形成产业。二战后，Cordillera 的“indigenous tea”由地方群体小规模加工；2000 年代后健康消费与奶茶连锁推动进口茶包增长。2023 年 FFCCCII、DA、DTI、Benguet 省政府与 BSU 联合推动茶区发展。

品种与工艺

以中国类型（sinensis）为主，适合高山；也有阿萨姆杂交试验。小农手工采摘，加工多为绿茶、红茶与乌龙式做青；设备简单、批次小，杀青与揉捻是瓶颈。高地昼夜温差有利于香气，但雨水多、萎凋难。

茶类与风味

本地茶以绿茶与轻发酵茶为主，汤色浅，带青草、栗子与花香；红茶较少，浓度中等。市场主流是进口红茶包、奶茶、即饮茶与调味茶；本地茶多在旅游地、农场直卖与少量精品店。Sagada 以咖啡闻名，不是茶产区，不要把“萨加达”自动当成茶。

产业与市场

没有大型商业茶园，产量远低于消费；进口茶包与奶茶原料主导。价格从本地小批量的高价到进口袋泡的低价并存。政府推动的 Cordillera 茶计划强调替代作物、防止水土流失与旅游；但苗圃、加工与品牌仍是瓶颈。

冲泡与到访

本地绿茶 80–85℃、2 分钟；红茶 90–95℃、3 分钟；乌龙 90℃、短泡。到访 Benguet 与 Sagada 以 11–4 月旱季为宜；山地路况与台风季要留余量。买本地茶要看加工日期与农场，不要只看“高山”。

常见误解与边界

“菲律宾没有茶”不对，但“菲律宾是产茶大国”也不对。它有零散茶园与潜力，没有规模产业；Sagada 的成名作物是咖啡，不是茶。进口茶包与奶茶才是日常主流。

Cordillera 茶计划与现实

2023 年的 Cordillera 茶计划把茶当作替代作物：高地坡地种茶可减少水土流失，茶青比蔬菜更耐运输，采摘期长，适合小农。Benguet State University 的可行性研究关注品种、苗圃、加工与市场；FFCCCII 与中国使馆提供技术与资金兴趣。现实困难是苗圃不足、加工设备贵、农户缺技术、品牌弱，且台风与暴雨会打乱采摘。政策热度还没有变成稳定的商业产量。另一个常被忽略的点是“indigenous tea”并不等于 Camellia 的商业品种：部分地方群体采集的是山茶科近缘植物或地方群体种，工艺与风味都未标准化，不能直接当作产地茶。进口茶包、奶茶粉与即饮茶仍是日常消费的基本盘。

菲律宾的茶消费增长主要来自奶茶与即饮茶，而非家庭清饮；这使进口碎茶与茶粉的需求远大于本地叶茶。只要奶茶链条存在，进口依赖就不会因为几片高地茶园而改变。
