坦桑尼亚的茶在南部高地与坦噶：Mbeya、Njombe、Tanga 的茶园，以 CTC 红茶和小农体系进入东非市场。

先看结论

坦桑尼亚茶区主要在南部高地（Mbeya、Njombe、Rungwe）与东北部 Tanga 一带，海拔 1,000–2,000 米。茶在 20 世纪初由德国与英国殖民者引入，独立后成为重要出口作物；今天以 CTC 红茶为主，小农比例上升。读坦桑尼亚，要理解“南部高地 + 小农 + 拍卖”的结构。

地理与产茶条件

南部高地气候温和、雨量充沛，火山土肥沃，茶园多在 1,000–2,000 米；Tanga 的 Usambara 山脉更靠近海岸，湿度高。坦桑尼亚茶区雨量分布不均，旱季需要灌溉，道路与加工设备是约束。

风土与季节

南部高地 Mbeya、Njombe、Rungwe 的采摘高峰多在 5–9 月，昼夜温差让芽叶积累更多滋味物质；北部 Tanga 与 Usambara 受印度洋影响，雨季更长，全年有茶可采。冰雹与干旱是高地茶园的常见风险。

历史与产业

德国殖民者在 20 世纪初于 Tanga 与南部高地引入茶树，英国时期扩大；独立后，茶园部分国有化，后又私有化。20 世纪后期，小农种植扩大，坦桑尼亚成为东非重要红茶产国。拍卖市场与出口体系延续至今。

品种与工艺

坦桑尼亚在 1900 年代初引入茶树，商业茶园分布在南部高地 Mbeya、Njombe、Rungwe、Mufindi 与北部 Tanga、Usambara。主栽 TRFK 与当地选育无性系，CTC 与 orthodox 并存；南部高地昼夜温差大，芽叶生长慢，适合做浓度与香气兼顾的红茶。

茶类与喝法

坦桑尼亚以 CTC 红茶为主，汤色深红、浓度高，适合袋泡与奶茶；也有少量 orthodox 与绿茶。国内消费以加糖红茶为主，精品单一园较少。坦桑尼亚茶常进入东非与欧洲拼配。

采摘与等级

CTC 以 BP1、PF、PD 与 fannings 分级，适合袋泡与奶茶；orthodox 看 OP、BOP、TGFOP 等芽叶等级，南部高地的春季批次香气更清。买 Tanzanian 茶要区分南部高地与北部产区，两者的浓度和香气结构不同。

产业与市场

茶叶是坦桑尼亚的重要出口作物，主要由庄园与小农交叶给工厂，经蒙巴萨拍卖进入国际拼配。国内消费以加糖红茶为主，精品单一园少；价格受拍卖、降雨与劳工成本影响，南部高地的小农组织是产业关键。

一杯茶的样子

坦桑尼亚 CTC 汤色红亮、浓度中等偏强，麦芽与果香并存，加奶后口感圆；南部高地 orthodox 更清爽，带柑橘、花香与蜂蜜尾。北部 Usambara 的批次有时更柔、更香。

适合谁喝

适合日常奶茶、早餐茶与想要“浓度不压香”的红茶爱好者；清饮可选南部高地 orthodox。想找极轻香、低涩感的人，应优先试小批次而不是大宗 CTC。

选购与边界

坦桑尼亚茶多以拼配出现；买单一庄园要看 Mbeya/Njombe/Tanga、等级与年份。CTC 用 95–100℃、加奶；orthodox 90–95℃。小农鲜叶与庄园茶品质差异大，价格不是唯一指标。

到访与冲泡

南部高地 5–9 月是主要采季，Mbeya 与 Njombe 可串联 Rungwe 茶园；北部 Tanga 与 Usambara 更湿润。CTC 用 95–100℃、加奶；orthodox 用 90–95℃ 清饮，先闻其果香与麦芽，再决定浸泡长度。

常见误解

“坦桑尼亚只有咖啡”是旅游叙事造成的盲区。坦桑尼亚有百年茶产业，南部高地与北部 Usambara 都有商业茶园；只是茶不如咖啡和丁香出名，出口以大宗红茶为主。

南部高地

坦桑尼亚茶区在南部 Mufindi、Njombe 与 Mbeya：海拔 1,200–1,800 米，1920 年代引入，主做红茶与少量绿茶；庄园与小农并存，CTC 与 orthodox 都有。采摘全年，旱季 6–10 月品质较稳。

来源边界

坦桑尼亚茶区集中在南部高地与 Tanga，不是全国产茶；CTC 大宗茶是主体，精品茶比例小。殖民历史与当代小农结构应分开看。
