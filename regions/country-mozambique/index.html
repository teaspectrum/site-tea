莫桑比克的茶在赞比西亚的 Gurué 高地：殖民茶园、内战破坏与近年恢复，构成一个“被遗忘的非洲茶区”。

先看结论

莫桑比克茶区集中在赞比西亚省（Zambézia）Gurué 一带的高地，海拔 1,000–1,500 米，气候凉爽、雨量充沛。茶在殖民时期建立，独立后因战争几乎毁灭；2000 年代后有少量恢复。读莫桑比克，要理解“殖民茶园遗产 + 战争断裂 + 小规模复兴”的轨迹。

地理与产茶条件

Gurué 位于莫桑比克中部高地，靠近马拉维边境，山地、红土与森林交错，气候比沿海凉爽。茶园多在 1,000–1,500 米，云雾与降水适合茶树；但道路、电力与加工设备在战争中受损，恢复缓慢。

风土与季节

Gurué 高地的采摘高峰在 11–4 月，雨季让山路与鲜叶运输变得困难；5–10 月偏干，茶园需要遮阴与灌溉。老茶园恢复后，采摘标准与工厂开机率仍在磨合，批次稳定性有限。

历史与产业

葡萄牙殖民者在 20 世纪中期于 Gurué 建立茶园与加工厂，使莫桑比克成为区域茶产地。1975 年独立后，内战与国有化破坏产业，茶园荒废。1990 年代和平后，少量私人投资恢复种植，但规模远低于殖民时期。

品种与工艺

莫桑比克茶区集中在赞比西亚省 Gurué 一带的高地，海拔约 1,000–1,500 米，主栽阿萨姆杂交与当地品系，以 CTC 与 orthodox 红茶为主。殖民时期留下的老茶园在内战中被荒废，近年由小农与新旧庄园逐步恢复，加工设备与电力仍是瓶颈。

茶类与喝法

莫桑比克以红茶为主，CTC 与 orthodox 都有，汤色深、浓度高；也有少量绿茶。国内消费以加糖红茶与茶包为主，精品茶几乎不存在。Gurué 茶多用于本地与区域拼配。

采摘与等级

CTC 以 BP、PF、PD 与 fannings 分级，适合袋泡与奶茶；orthodox 以 OP、BOP 与芽头等级区分，产量小。买莫桑比克茶要确认庄园、加工点与年份，尤其要警惕只写“Gurué”却没有生产信息的旅游包装。

产业与市场

莫桑比克茶叶产量小，主要供国内与区域市场，少量进入欧洲精品渠道；Gurué 的复兴项目用有机与社区叙事寻找溢价，但物流、融资与气候风险限制规模。市场上“莫桑比克白茶”等新品类需要谨慎核实产地与工艺。

一杯茶的样子

Gurué 的 orthodox 红茶汤色红亮，入口中等厚度，带花香、木质与一点柑橘；CTC 更浓、更快出汤，适合袋泡。恢复期批次的干净度不一，好茶往往有明显的甜感和较轻的涩。

适合谁喝

适合想找小众产区、愿意接受批次差异的清饮者；日常奶茶则选 CTC。购买时要看具体庄园与加工点，不要被“战後复兴”“有机”故事替代品质判断。

选购与边界

莫桑比克茶产量小、可追溯性差；买 Gurué 茶要看具体庄园、合作社与加工日期。红茶用 95–100°C、可加奶；绿茶 85–90℃。战后恢复中的供应链不稳定，价格与真伪差异大。

到访与冲泡

Gurué 的采季集中在 11–4 月，雨季山路难走；参观茶园要预留交通时间。CTC 用 95–100℃、加奶；orthodox 用 90–95℃ 清饮，先闻其花香与木质调，避免长时间浸泡。

常见误解

“莫桑比克茶已经消失”过于绝对。内战确实摧毁了大部分老茶园，但 Gurué 仍有恢复中的茶产业；它规模小、波动大，不能拿殖民时期的产量想象今天。

来源边界

莫桑比克茶区只在赞比西亚 Gurué 高地，不是全国产茶；殖民产量与今天不可比。战争与土地制度对产业影响很大，本页不做“非洲茶新兴大国”的夸张。
