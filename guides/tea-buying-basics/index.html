买茶基础

导览 · Tea Buying Basics

买茶不是背等级缩写，也不是只看产地。先确定你要什么类型的茶，再看干茶、香气、工艺、日期、包装与可试饮性；等级字母多描述叶片大小与含芽量，不直接等于杯中的好坏。

买茶最容易犯的错，是把“信息”当成“品质”：等级字母越长越好、产地越有名越好、价格越贵越好。这些信号有用，但都不能单独决定一杯茶。更可靠的做法是先明确你要喝什么，再用干茶、香气、工艺、日期、包装与试饮去验证。

先确定需求，再看茶

需求 优先看 不必执着
日常口粮 新鲜度、稳定性、单价、耐泡度 稀有等级、复杂故事
送礼 包装完整性、品牌可追溯、批次说明 过度包装、无法验证的“大师作”
尝鲜 小样、工艺特色、产地差异 大罐囤货
长期存 含水量、工艺、仓储条件、原料 所有茶都“越陈越香”
调饮 浓度、香气强度、价格 名优等级

先买小样，是最便宜的避坑方式。同一款茶，10 g 试饮与 500 g 囤货的风险完全不同。

等级字母到底说什么

红茶贸易中的 OP、FOP、GFOP、TGFOP、FTGFOP 等，主要描述叶片大小、完整度与含芽量；CTC 的 BP1、PF1、PD、Dust 则按颗粒大小分级。它们描述的是物理外观与筛分结果，不是杯中的风味评分。

  • OP：Orange Pekoe，较长、较完整的叶片，通常无芽尖。
  • FOP：Flowery Orange Pekoe，含少量嫩叶与芽尖；“Flowery”指采摘部分，不是花香。
  • TGFOP / FTGFOP：含芽尖比例更高、筛分更细；数字 1 常表示同批中更高等级。
  • CTC：Crush–Tear–Curl，颗粒状，浸出快、浓度高，常见于茶袋与奶茶。

等级高不等于你更喜欢。有人爱 FTGFOP 的清透，也有人爱 CTC 的浓强。等级只帮你判断“这是什么形态”，不替你判断“好不好喝”。

干茶能看出什么

  1. 颜色是否自然：同一批茶的颜色应相对一致；过度油亮、荧光感、明显灰白可能提示加工或仓储问题。
  2. 条索是否完整：整叶茶条索紧结；碎茶袋本来就不是整叶，不必用整叶标准要求。
  3. 是否结块、受潮：手捏应脆，不应软塌、成团。
  4. 香气是否干净：干茶应有茶香，不应有霉味、烟熏异味、香水或洗涤剂味。
  5. 是否有过多粉末：少量碎末正常；大量粉末可能影响冲泡与汤色。

香气与试饮

干茶香只是第一层。用同一套参数试泡：相同水量、水温、茶水比、时间与器具。参考 ISO 3103 的控制变量思路，至少试两泡，观察：

  • 热香、温香、杯底香是否一致；
  • 汤色是否透亮，是否浑浊；
  • 滋味是否有明显苦涩、酸馊、烟焦、霉味；
  • 口感是否顺，余味是否干净；
  • 第二、三泡是否快速掉水。

“第一泡很香、第二泡没味”的茶，可能香气集中在表面或工艺不足；但也要看你是否用对了水温与时间。

日期、包装与来源

  • 生产/分装日期：绿茶、清香乌龙越新鲜越好；红茶、焙火乌龙有适度的“退火期”；后发酵茶看仓储记录。
  • 包装：避光、密封、防潮优先；透明袋与纸袋不适合长期存。
  • 来源：能说清产地、品种、工艺与批次的商家，比只讲“古树/大师/核心产区”的更可核查。
  • 检测：农残、重金属、微生物报告要看检测基质与日期，不只看“合格”两个字。
  • 价格：贵可能来自原料、工艺、稀有度、包装或品牌；不等于你杯中的偏好。

四个常见陷阱

陷阱 问题 对策
“等级越长越好” 等级描述外观，不描述风味 试饮优先，等级作参考
“核心产区一定好” 产区内部差异大，批次与工艺更关键 看具体批次与试饮
“老茶越陈越香” 多数茶会劣变，潮湿会霉变 只存适合存的茶，控湿控氧
“零农残/有机=绝对安全” 有机主要管生产规范，不等于零残留 看标准、检测基质与来源

一个可执行的买茶流程

  1. 定类型与预算：先决定绿茶/乌龙/红茶/白茶/后发酵，避免被货架牵着走。
  2. 买小样：至少 2–3 款对比，记录冲泡参数。
  3. 盲评一次：先喝，再看价格与标签，减少期望偏差。
  4. 检查干茶与包装：受潮、霉味、结块直接排除。
  5. 确认日期与储存：问清出厂/分装时间与建议存法。
  6. 少量复购：喜欢再买大包装；不要第一次就囤一年。

来源边界

这页能确认：红茶等级主要描述叶片大小、完整度与含芽量；orthodox 与 CTC 是不同形态体系；干茶颜色、条索、香气、含水量与包装可作为选购信号；标准冲泡与盲评能降低比较偏差。

这页不能确认：某个等级一定比另一个好喝；某个产地或品牌一定优于其它；价格与品质的固定比例。具体购买应结合试饮、批次、检测与储存条件，不用单一标签代替判断。

品鉴词汇

品鉴词汇不是越玄越好。好的描述能指向具体对象与强度：干茶、茶汤、香气、滋味、口感、叶底分别说什么；“兰花香”“岩韵”这类词，需要拆成可观察的线索。

存茶中的化学

存茶不是“放得越久越值钱”。水分、氧气、温度、光照与残留酶活共同改变香气、汤色与滋味；绿茶、乌龙、红茶与后发酵茶的劣变路径不同，家庭存茶要先控湿、控氧、避光、隔味。
