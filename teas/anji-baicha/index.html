安吉白茶

中国 · 浙江省 · Anji Baicha

安吉白茶名字里有“白茶”，工艺上却是绿茶。它用“白叶一号”品种的白化期鲜叶为原料，按绿茶工艺制成，产品分凤形、龙形等。春季新芽玉白、叶脉浅绿，成品色泽翠绿间金黄，汤色鹅黄清亮，滋味鲜爽甘醇。现行标准为 GB/T 20354-2006，2026 版将于 2027-04-01 实施。

一句话定位

安吉白茶不是白茶，是绿茶。它的“白”来自品种：白叶一号在春季低温期新芽呈玉白色、叶脉浅绿，采下来按绿茶工艺杀青、理条、烘干，做成凤形或龙形。因为白化期芽叶里的氨基酸比例高、茶多酚相对低，茶汤特别鲜爽甘甜，苦涩很轻。它不像龙井那样追求豆香和扁平，也不像碧螺春那样细卷披毫，而是“鲜”字当头，汤色鹅黄，叶底玉白。

标准里的定义

GB/T 20354-2006《地理标志产品 安吉白茶》是现行国家标准，2006-05-25 发布、2006-11-01 实施。标准把安吉白茶定义为：产自规定范围内，采自“白叶一号”茶树鲜叶，经加工而成并符合标准要求的绿茶类茶叶。

标准还规定了两个产品形态：

  • 凤形安吉白茶：按条形茶工艺制作，工艺为摊青 → 杀青 → 理条 → 搓条初烘 → 摊凉 → 焙干 → 整理。
  • 龙形安吉白茶：按扁形茶工艺制作，工艺为摊青 → 杀青 → 摊凉 → 干燥。

2026 版标准 GB/T 20354-2026 已于 2026-03-31 发布，2027-04-01 实施，全面替代 2006 版；过渡期至 2027-04-01，其间 2006 版仍可执行。新版还新增了“兰花形”加工工艺。买茶时看到 2006 版或 2026 版标准号都可能合法，要看生产日期和包装标注。

品种与白化

安吉白茶的专用品种是白叶一号。标准描述它为灌木型、中叶类，主干明显，叶长椭圆形，叶尖渐突斜上，叶身稍内折，叶面微内凹，叶齿浅，叶缘平，中芽种；春季新芽玉白，叶质薄，叶脉浅绿色；气温高于 23°C 时，叶色逐渐转花白至绿。

“白化”是温度敏感现象，不是白化病，也不是把茶叶漂白。春季气温低时，新芽的叶绿素合成受抑制，叶片呈玉白或浅黄，叶脉仍绿；气温升高后，叶片逐渐转绿。白化期采的芽叶，氨基酸含量相对高，茶多酚相对低，所以滋味鲜、涩感弱。这个窗口很短，采早了芽没长足，采晚了叶已转绿，白化特征消失。

产地与风土

安吉白茶的地理标志保护范围是浙江省安吉县现辖行政区域。安吉在天目山北麓，属亚热带季风气候，四季分明、雨量充沛、云雾多。茶园多分布在丘陵山地，土壤以酸性黄壤、红壤为主，pH 值偏酸，排水要好，有机质丰富。

安吉白茶的品质不只看“白”。高山茶园昼夜温差大，白化期长，芽叶肥壮；低山茶园发芽早、产量高，但白化窗口短，香气和厚度可能弱一些。土壤、朝向、遮阴、采摘标准、加工火功，都会影响最终风味。

采摘

标准要求采摘一芽一叶初展至一芽三叶，不采病虫叶、不采冻伤叶。实际生产里，特级原料多采一芽一叶初展，一级、二级逐渐放宽。采摘期在清明前后至谷雨，白化期是核心窗口；天气突然升温，芽叶转绿，白化特征就弱了。

采下的鲜叶要薄摊，不能堆闷。摊青时间看天气和鲜叶含水量，目的是散青草气、适度失水，让叶片变软，便于杀青和理条。

工艺

凤形安吉白茶的工艺是：

摊青 → 杀青 → 理条 → 搓条初烘 → 摊凉 → 焙干 → 整理。

  • 杀青：高温快速破坏酶活性，固定绿色和鲜爽。标准要求“高温杀青，先高后低；抛闷结合，多抛少闷；嫩叶老杀，老叶嫩杀”。
  • 理条：把茶叶理直、成条，凤形要求条索挺直如凤羽；龙形则用扁形茶工艺压扁。
  • 搓条初烘：边搓边烘，让条索紧结、白毫显露，同时去掉部分水分。
  • 摊凉、焙干：让水分重新分布，再低温慢烘到安全含水量。
  • 整理：筛去碎末、黄片，分级包装。

安吉白茶的核心是“保绿、保鲜”：杀青要透而不能过，理条要挺而不能碎，烘焙要干而不能焦。火功太重，鲜爽变熟闷、色泽变黄；火功不足，青草气重、含水量高，容易变质。

品质

干茶条索挺直或扁直，色泽翠绿间金黄，白毫显露。汤色鹅黄清亮，香气清幽，带嫩香、栗香或兰花香。滋味鲜爽甘醇，入口即甜，苦涩极低，回甘绵长。叶底玉白柔软，叶脉翠绿，芽叶完整。

“鲜如鸡汤”是市场比喻，不是标准术语。安吉白茶的鲜，来自高氨基酸、低茶多酚和适当的火功；但不是所有安吉白茶都鲜，采摘过老、杀青不当、烘焙过火，都会让鲜爽变成青味或熟味。

冲泡

  • 水温：80–85°C。芽叶嫩，沸水容易把鲜爽烫成熟闷。
  • 投茶量：3–4 克/200 毫升玻璃杯。
  • 方法：玻璃杯先水后茶，看芽叶舒展；也可用盖碗，出汤要快。
  • 出汤：前几泡 20–30 秒，后面逐泡延长；不要长时间闷盖。
  • 器具：玻璃杯最能看“玉白叶底”，白瓷盖碗便于控制。

等级与选购

GB/T 20354-2006 对安吉白茶分级，市场常见“特级、一级、二级”。选购时看：

  1. 产地：是否在安吉县现辖行政区域内，包装是否有地理标志专用标志。
  2. 品种：白叶一号；不是所有白色芽叶的茶都叫安吉白茶。
  3. 外形：凤形条索挺直、翠绿间金黄；龙形扁平挺直；白毫自然，不是撒粉。
  4. 香气：清幽嫩香、栗香或兰花香，不是青草气、烟焦味。
  5. 滋味：鲜爽甘醇、苦涩低，不是寡淡或涩口。
  6. 叶底：玉白柔软、叶脉翠绿，芽叶完整。
  7. 标准号：2006 版或 2026 版；2027-04-01 前旧版仍可执行。

历史与名称

安吉白茶的名字容易让人误会。它历史上可能有过“白茶”的叫法，但现代安吉白茶是 20 世纪后期从安吉当地发现的白叶一号母树选育、推广而来的绿茶品种，不是宋徽宗《大观茶论》里说的那种“白茶”。旧稿把《大观茶论》的“白茶”直接等同于安吉白茶，这是不准确的；两者时代、产地和工艺都不同。

可以确认的是，白叶一号在安吉被发现并选育后，逐步推广到安吉县及周边；2006 年 GB/T 20354-2006 发布，把安吉白茶纳入地理标志产品体系；2026 年新版标准发布，增加了兰花形工艺和更细化的质量要求。

泰国

安康山绿茶（Doi Ang Khang Green Tea）

安康山绿茶是泰国清迈芳县 Doi Ang Khang 的皇家项目有机绿茶产品，不是茶树品种，也不是“泰国绿茶”的统称。皇家项目官方产品页只说明它是有机、不发酵绿茶，带坚果或海苔气息，口感柔和；没有公开品种、杀青方式或固定冲泡参数。它的产地背景是 1969 年设立的皇家农业站：海拔约 1,400 米，位于泰缅边境，用温带作物替代罂粟种植。理解这款茶，要把它放回“皇家项目 + 清迈高山 + 有机绿茶产品”这三个确定坐标里。

日本

八女抹茶

八女抹茶是福冈县八女地区出产的抹茶，属于“产地 + 茶类”的组合，不是茶树品种，也不是一个受保护的等级。八女在日本更出名的是玉露；抹茶和碾茶是当地另一条产品线。它的风格通常被描述为旨味厚、甜感足、苦味相对低，但具体仍取决于品种、遮光和研磨方式。
