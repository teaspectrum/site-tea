清香型铁观音

中国 · 福建省 · Light-Aroma Tieguanyin

清香型铁观音是安溪铁观音三大产品类型之一（另为浓香型、陈香型）。它以铁观音品种芽叶为原料，经萎凋、做青、杀青、揉捻、包揉、烘干制成毛茶，再经拣剔、筛分、拼配、文火烘干精制。条索紧结砂绿，汤色金黄明亮，香气清高，滋味鲜醇甘爽，音韵明显。

一句话定位

清香型铁观音是安溪铁观音里最“清”的一路：条索紧结、色泽砂绿油润，汤色金黄明亮，香气清高，入口鲜醇甘爽，咽下去后喉咙里有“音韵”。它和浓香型、陈香型不是三个品种，而是同一品种、同一产区、不同精制工艺形成的三种产品类型。喜欢绿茶那种清鲜、又想要乌龙茶厚度的人，通常会从清香型入门。

标准里的分类

GB/T 19598-2025《地理标志产品质量要求 安溪铁观音》于 2025-02-28 发布、2025-09-01 实施，代替 GB/T 19598-2006。标准把安溪铁观音按精制工艺分为三类：

  • 清香型：毛茶经拣剔、筛分、风选、拼配、匀堆，再经文火烘干。
  • 浓香型：在清香型精制基础上增加烘焙，可用炭焙或电焙，温度 90–150°C。
  • 陈香型：毛茶烘足干后，在干燥、避光、防潮、防异味环境中贮存 5 年及以上。

所以“清香型”不是“没有工艺”，更不是“不焙火”。它仍然要经过文火烘干，只是火功轻、温度低（60–90°C），目的是把水分降到 7% 以下、固定香气，而不是用高温烘焙制造火香。

产地与品种

安溪铁观音的地理标志保护范围是福建省安溪县现辖行政区域。安溪县政府资料说明，铁观音既是茶树品种名，也是茶叶商品名，原产西坪尧阳，主要分布在祥华、感德、西坪、虎邱、剑斗等乡镇。这里峰峦多、云雾多、土壤以红壤和赤红壤为主，适合铁观音品种生长。

清香型铁观音的原料必须是铁观音茶树品种的芽叶。标准附录 C 的采摘要求是：芽梢驻芽形成后，顶叶小开面至大开面；标准芽叶为 1 芽 2 叶至 4 叶，含嫩梢及幼嫩对夹叶；春茶在谷雨前后至立夏前后，夏暑茶在夏至前至秋分，秋（冬）茶在寒露前至立冬。采下的茶青要肥壮、完整、新鲜、均匀。

工艺

清香型铁观音的工艺分初制、精制两段。

初制：茶青 → 萎凋（晒青）→ 晾青 → 摇青 → 杀青 → 揉捻 → 初烘 → 初包揉 → 复烘 → 复包揉 → 烘干 → 毛茶。

  • 萎凋：自然萎凋 3–6 小时，或日光萎凋 15–60 分钟，失水率 5%–15%；阴雨天可用热风萎凋。
  • 做青：晾青和摇青反复 3–5 遍，历时 10–16 小时。摇青让叶缘细胞受损、促进氧化，晾青让水分重新分布。清香型的做青程度较轻，发酵程度低于传统浓香型，但具体程度要看师傅对茶青的判断，标准没有给一个固定百分比。
  • 杀青：260–300°C，终止酶活性，固定香气。
  • 揉捻、包揉：热揉、少量、逐渐加压，初包揉和复包揉各 3–5 遍，把条索揉紧、揉成半球形。
  • 烘干：60–90°C 低温慢烘，毛茶含水率低于 7%。

精制：毛茶 → 验收 → 拣剔 → 归堆 → 筛分 → 风选 → 拣杂 → 号茶拼配 → 匀堆 → 文火烘干 → 包装。清香型的精制不经过高温烘焙，火功轻，所以香气偏清、偏兰花香，汤色也比浓香型浅。

品质

按 GB/T 19598-2025，清香型安溪铁观音分特级、一级、二级、三级。特级的要求是：条索肥壮紧结，色泽油润、砂绿明显，匀整、洁净；香气高香；滋味鲜醇甘爽、音韵明显；汤色金黄明亮；叶底肥厚、软亮、匀整、余香高长，有红点或红边。一级是条索壮实紧结、较油润、砂绿较明显，香气清高持久，滋味较鲜醇甘爽、音韵较明显。二级、三级依次放宽。

“音韵”是安溪铁观音的术语，标准把它定义为品种香、地域香、工艺香和滋味的综合体现。它不是一种可以单独闻到的香精味，而是兰花香、奶香、果香、矿物感、回甘和喉韵混在一起的整体感受。清香型的音韵通常比浓香型更清、更飘，但好的清香型仍然有厚度，不是只有香气没有茶味。

冲泡

  • 水温：95–100°C。清香型虽然火功轻，但乌龙茶需要高温才能出香。
  • 投茶量：7–8 克/120–150 毫升盖碗。颗粒紧结，投茶量要足。
  • 醒茶：第一泡快速洗茶，帮助颗粒舒展。
  • 出汤：前几泡快进快出，5–10 秒；后面逐泡延长。不要久浸，否则苦涩。
  • 器具：白瓷盖碗最宜，便于闻香和控制；紫砂壶会吸附部分清花香。

选购

  1. 看外形：颗粒紧结、圆润、重实，色泽砂绿油润，不是死绿或灰暗。
  2. 闻香气：清高、兰花香或花果香，不刺鼻、不腻、不焦。
  3. 看汤色：金黄明亮，不浑浊、不暗沉。
  4. 尝滋味：鲜醇甘爽，有回甘和音韵，不苦涩、不锁喉。
  5. 看叶底：肥厚软亮，有红点或红边，不是死绿叶。
  6. 认标志：安溪全县授予 145 家茶企使用地理标志（截至安溪县政府专访时）；包装上的地理标志和专用标志可查授权企业。

与浓香型、陈香型的关系

  • 清香型：火功轻，香气清高，汤色金黄，滋味鲜爽，适合日常清饮。
  • 浓香型：经过 90–150°C 烘焙，色泽乌润，汤色金黄至橙黄，香气浓郁，滋味醇厚，火香和熟果香更明显。
  • 陈香型：贮存 5 年以上，汤色橙红，香气陈香，滋味醇和，是另一种审美。

三者没有绝对高下，只看原料、工艺和仓储是否到位。清香型不是“低端版”，浓香型也不是“升级版”；它们对应不同的风味偏好和饮用场景。

历史与标准

铁观音的品种和商品名关系、原产地与主要产区，安溪县政府的资料写得很清楚；但“皇帝赐名”“某年发现铁观音”之类传说，本文不作为史实。可以确认的是，安溪铁观音是地理标志产品；2025 年新版国家标准 GB/T 19598-2025 实施，把清香型、浓香型、陈香型三类产品的工艺和感官要求写入标准。

旧稿中的“1990 年代安溪茶人创新”“发酵度 15%–20%”“不焙火或极轻焙火”“2000 年代占市场 80% 以上”“茶性偏寒伤胃”“安溪全境茶园 60 万亩”“祥华、感德、西坪海拔 600–1000 米”等具体数字和因果判断，本文没有找到完整、可核验的官方来源，因此删除或改为定性描述。清香型的确切起源年代，现有官方标准和生产资料没有给出统一口径，本文不硬填年份。

来源与状态

白芽奇兰

白芽奇兰是闽南乌龙茶的后起之秀，也是平和县最具特色的乌龙茶品种，有"平和第一茶"之称。因茶芽白毫显露如银、香气奇绝似幽兰而得名——"奇兰"之"奇"在于其兰花香气之奇特高扬难以复制。外形紧结匀整，色泽砂绿油润。冲泡后兰花香清雅高扬扑鼻而来，香气奇绝，汤色金黄明亮，滋味醇厚甘爽。

保禄乌龙（Trà Ô Long Bảo Lộc）

保禄乌龙（Trà Ô Long Bảo Lộc）是越南林同省保禄（Bảo Lộc）一带的乌龙茶产区与产品家族，不是单一品牌，也不是“越南铁观音”的同义词。保禄位于海拔约 800 米的林同高原，夜间和清晨多雾、昼夜温差大，土壤为深厚风化的玄武岩土。当地茶园由本地种、Shan 种和引进的乌龙品种共同构成。保禄乌龙出口俄罗斯、法国、美国、印度、日本、泰国、印尼、新加坡、台湾、香港和中东；Bao Loc VN、Kim Điền 等企业各有不同规模。

翠峰乌龙

翠峰乌龙不是单一茶树品种，也不是一个产区等级，而是泰国清莱翠峰茶园（Choui Fong Tea）的乌龙产品线。它以金萱、软枝乌龙等品种为主，做半发酵乌龙，既有纯茶单品，也有桂花加花产品和头采限量版。
