八女抹茶

日本 · Yame Matcha

八女抹茶是福冈县八女地区出产的抹茶，属于“产地 + 茶类”的组合，不是茶树品种，也不是一个受保护的等级。八女在日本更出名的是玉露；抹茶和碾茶是当地另一条产品线。它的风格通常被描述为旨味厚、甜感足、苦味相对低，但具体仍取决于品种、遮光和研磨方式。

先说清楚：这是一个产地名，不是品种名

“八女抹茶”可以拆成两层：八女是产地，抹茶是茶类。它指用福冈县八女地区种植、加工的碾茶（tencha）磨成的抹茶，不是一种茶树品种，也不是日本官方划分的某个固定等级。

八女在日本茶版图里更响的名片是玉露。福冈县官方资料把八女玉露、八女传统本玉露放在很高的位置；抹茶和碾茶是同一片产区里的另一条产品线。所以不要把“八女抹茶”理解成“八女玉露磨成的粉”——玉露和碾茶是两种不同的栽培/加工目标，虽然都用到遮光。

同样，抹茶也不等于“把绿茶磨成粉”。真正的抹茶原料是碾茶：遮光栽培、蒸青、不揉捻、干燥后去掉叶脉，再研磨成粉。粉末细、颜色绿、能点茶起泡，是工艺结果，不是随便磨一磨就能得到。

八女在哪里，为什么适合做茶

八女位于福冈县南部，属于九州北部的筑后地区，主产区沿矢部川流域展开。官方资料描述的典型条件是：降雨充足、昼夜温差大、山间容易起雾，茶园多在缓坡和中山间地。雾和山间温差会减弱强光、拉长新梢的生长时间，对制造厚实的旨味有帮助。

八女茶的历史通常追溯到 1423 年：荣林周瑞禅师从中国带回茶种和制茶方法，在现在的八女市黑木町一带传播。江户时代茶作扩大，明治以后转向蒸青绿茶；今天八女以玉露、煎茶为主，也有碾茶和抹茶。这个时间线是产地叙事，不等于“八女抹茶从 1423 年就有”；抹茶作为专门品类，是后来工艺分工的结果。

抹茶是怎么做出来的

  1. 遮光：采摘前一段时间覆盖茶棚，减少直射光。八女传统玉露用稻秸秆，抹茶/碾茶则常用遮阳网或棚架；具体方式因农户而异。
  2. 采摘：碾茶通常采一芽二叶到一芽三四叶，讲究嫩度和匀整。顶级抹茶会强调一番茶。
  3. 蒸青：短时间蒸汽杀青，固定颜色和风味。
  4. 不揉捻、干燥：与煎茶不同，碾茶不揉成条索，而是保留叶片后干燥。
  5. 去梗去脉：把叶脉、叶梗分离，留下叶片部分。
  6. 研磨：传统用花岗岩石磨，低温慢磨；现代也有球磨机。石磨不是唯一合法方式，但低速低温研磨通常更有利于保留香气和颜色。

八女抹茶的具体风格，和品种关系很大。日本常见抹茶品种有 Okumidori、Saemidori、Asahi、Yamashiro 等；八女也有用 Okumidori、Saemidori 的产品。品种决定甜度、旨味、颜色和苦味，不能只看“八女”两个字。

风味：旨味厚，甜感足，苦味通常较低

八女茶的整体风格，官方描述是“甜、旨味强、涩味较少”。抹茶因为整片茶叶被吃下去，旨味和苦味都会被放大：好的八女抹茶通常入口厚、甜感先到，海苔般的鲜香在中段出现，苦味在尾部收得比较干净。

但“八女抹茶一定不苦”不成立。苦味受品种、遮光时间、采摘嫩度、研磨细度和冲泡浓度影响。薄茶（usucha）用 1.5–2 克抹茶配 60–70 毫升水，通常更轻；浓茶（koicha）用 3–4 克配 30–40 毫升水，旨味更集中，苦味也更明显。

点茶方法

  • 薄茶：抹茶 1.5–2 克，水 60–70 毫升，水温 70–80°C。先筛粉，再少量水调成糊，补足水后用茶筅“W”形快速击拂，直到细密泡沫。
  • 浓茶：抹茶 3–4 克，水 30–40 毫升，水温 70–80°C。不追求厚泡沫，慢慢搅匀，口感像浓稠的茶浆。
  • 不要用沸水直接冲：高温会放大苦味和涩感，也会让香气变钝。
  • 抹茶容易氧化，开封后冷藏、避光、尽快用完。

买茶时看什么

  1. 产地：包装写“八女产”只说明原料来自八女，不说明品种、采摘季或研磨方式。
  2. 用途： ceremonial / drinking 与 culinary / cooking 是两条产品线；食用级抹茶可以更苦、更便宜，点茶级通常更细、更鲜。
  3. 品种：Okumidori、Saemidori、Asahi 等会带来不同甜度和旨味；包装不写品种时，不要假设。
  4. 颜色和香气：新鲜抹茶是鲜绿、有海苔/嫩叶香；发黄、发灰、闻起来像干草，通常不新鲜。
  5. 研磨：石磨、球磨、气流磨都合法；关键看粉末细度、温度和是否氧化，不是“石磨”两个字本身。

来源与状态

本页依据福冈县政府特集、八女茶产地协议会页面与福冈县官方旅游指南。三份资料支持八女茶的地理、历史、玉露工艺和“甜、旨味强”的风格；抹茶的碾茶工艺与点茶方法属于日本抹茶通识，正文用“通常/常见”限定，不把某一家的做法写成全产区标准。八女抹茶没有被写成一个独立的地理标志等级，也没有被夸成“世界第一”。

日本茶区

日本茶以煎茶为主体，宇治抹茶、玉露、焙茶、玄米茶与红茶各有工艺。静冈、鹿儿岛、京都、福冈是核心产区，遮光、蒸青、揉捻、焙火与研磨把同一片叶子做成不同茶类。

中国 · 浙江省

安吉白茶

安吉白茶名字里有“白茶”，工艺上却是绿茶。它用“白叶一号”品种的白化期鲜叶为原料，按绿茶工艺制成，产品分凤形、龙形等。春季新芽玉白、叶脉浅绿，成品色泽翠绿间金黄，汤色鹅黄清亮，滋味鲜爽甘醇。现行标准为 GB/T 20354-2006，2026 版将于 2027-04-01 实施。

泰国

安康山绿茶（Doi Ang Khang Green Tea）

安康山绿茶是泰国清迈芳县 Doi Ang Khang 的皇家项目有机绿茶产品，不是茶树品种，也不是“泰国绿茶”的统称。皇家项目官方产品页只说明它是有机、不发酵绿茶，带坚果或海苔气息，口感柔和；没有公开品种、杀青方式或固定冲泡参数。它的产地背景是 1969 年设立的皇家农业站：海拔约 1,400 米，位于泰缅边境，用温带作物替代罂粟种植。理解这款茶，要把它放回“皇家项目 + 清迈高山 + 有机绿茶产品”这三个确定坐标里。
