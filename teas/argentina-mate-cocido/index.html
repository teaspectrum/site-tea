马黛煮茶（Mate Cocido）

阿根廷 · Mate Cocido

Mate cocido 是把马黛茶用沸水冲泡或短时间煮、再过滤到杯子里喝的饮法，类似茶包茶。它比葫芦杯热饮更浓、更苦，常加糖、牛奶或柠檬，是阿根廷家庭、学校、医院和咖啡馆的日常饮品。

一句话定位

Mate cocido 是马黛茶的“杯子版”。不用葫芦杯和金属吸管，而是把马黛茶放进茶壶或杯子，用沸水冲泡或短时间煮，过滤后像茶一样喝。它比葫芦杯热饮更浓、更苦，也更方便：可以加糖、牛奶、柠檬，也可以做成冰饮。

名字

“Cocido”在西班牙语里是“煮过的”。但在阿根廷和乌拉圭，很多 mate cocido 其实只是“泡”出来的，不一定真煮。超市里卖的是茶包或散装细研磨马黛茶；咖啡馆、学校、医院里常用大壶冲泡，加糖或牛奶。

在巴西，类似的饮品叫 chá mate；在巴拉圭，常直接叫 cocido。它们不完全相同，但都属于“马黛茶泡出/煮出后过滤饮用”的家族。

怎么做

茶包法

  1. 水烧到沸腾，离火；
  2. 每 200 毫升水放 1 个马黛茶包；
  3. 浸泡 3–5 分钟；
  4. 取出茶包，按口味加糖、蜂蜜、牛奶或柠檬。

散茶法

  1. 每 200 毫升水放 5–8 克马黛茶；
  2. 水沸腾后离火，倒入茶，浸泡 3–5 分钟；
  3. 用细滤网过滤；
  4. 不要大火长时间滚煮，否则苦涩和烟熏味会过重。

煮法

传统做法可以把马黛茶和水一起煮几分钟，再过滤。煮出来的茶更浓、更苦，适合加牛奶做成早餐茶。煮的时间越长，苦味越重；一般 3–5 分钟足够。

风味

  • 干茶：细碎墨绿叶片 + 少量梗，闻起来草木、烟熏、干草。
  • 汤色：黄绿至深琥珀，比葫芦杯热饮更深。
  • 香气：草木、烟熏、轻微烘焙；加牛奶后更柔。
  • 滋味：入口苦、浓，回甘快；比热饮马黛更直接、更“茶”。
  • 口感：干净、薄，没有葫芦杯的“吸管过滤”口感。

咖啡因

INYM 的资料显示：

  • 500 毫升热饮马黛约 0.35–0.45 克咖啡因；
  • 500 毫升 tereré 约 0.2 克；
  • 200 毫升 mate cocido 约 0.02–0.04 克。

mate cocido 的单位咖啡因看起来低，是因为通常一杯只有 200 毫升；如果喝大杯或浓泡，总量会增加。对咖啡因敏感的人，下午以后少喝。

怎么喝

  • 早餐：热 mate cocido + 牛奶 + 糖，配面包。
  • 日常：清饮，不加糖，配一点柠檬皮。
  • 冰饮：泡浓一点，冷却后加冰、柠檬汁，类似冰茶。
  • 调味：香草、肉桂、橙皮都可以；不要用香精糖浆代替真材料。

与热饮马黛的区别

器具 葫芦杯 + 金属吸管 壶/杯 + 滤网或茶包
水温 70–95°C 沸水
浓度 中等、可反复续水 较浓、一次泡好
添加 少糖或无糖 糖、牛奶、柠檬常见
场景 社交、日常、户外 早餐、学校、医院、咖啡馆

选购与保存

  1. 茶包：看生产日期、密封性；茶包里的马黛茶通常研磨较细，出味快。
  2. 散茶：选细研磨或中研磨，适合壶泡；粗研磨更适合葫芦杯。
  3. 产地：米西奥内斯、科连特斯产区。
  4. 味道：干净草木、轻烟熏；不要霉味、酸味、刺鼻烟焦。
  5. 保存：密封、避光、防潮；开封后尽快用完。

文化位置

阿根廷第 26.871 号法律把 mate 宣布为“国民饮品”，并规定在官方文化、社会、体育活动中推广马黛茶传统。Mate cocido 是这种国民饮品的“家常形式”：它不像葫芦杯那样有强烈的仪式感，但更便宜、更方便，所以在学校、医院、办公室和家庭早餐里更常见。

来源与状态

本文依据 INYM 的饮用方式资料和阿根廷国家政府官网“El mate”页。前者支撑 mate cocido 的定义、冲泡方式和咖啡因数据；后者支撑马黛茶的植物学背景、耶稣会种植史和“国民饮品”法律地位。旧稿中的“马黛茶是阿根廷国茶”“mate cocido 是穷人饮料”“咖啡因比咖啡高十倍”等未经证实的说法，已删除。所有迁移页面当前统一标为 reviewed，但来源与措辞仍会继续修订。

马黛茶

马黛茶是用冬青科植物 Ilex paraguariensis 的叶和嫩茎制成的南美传统饮品，不是山茶属茶。阿根廷把它称为“国民饮品”，主要产区在米西奥内斯和科连特斯。传统有热饮马黛、冰饮 tereré 和煮饮 mate cocido 三种形式，共用一个葫芦杯和金属吸管。

阿根廷冰马黛（Tereré）

Tereré 是用冷水或冰水冲泡马黛茶的饮法，在阿根廷东北部、巴拉圭和巴西南部都很常见。它和热饮马黛使用同一原料，但水温、器具和添加物不同；阿根廷做法常加冰块、柑橘、薄荷或果汁，茶味比热饮更清、更淡。

阿根廷有机马黛茶

有机马黛茶不是新植物品种，而是按阿根廷有机农业法规种植、采收、加工并经过第三方认证的 Ilex paraguariensis 产品。核心差异在土壤管理、禁用合成农药化肥、缓冲带、可追溯记录和认证标志，不在“有机就一定更好喝”。

阿根廷

带梗马黛茶

“Con palo”是带梗马黛茶。它把干燥叶片与一定比例的嫩茎、碎片混合，口感通常比去梗更圆润、更甜、刺激感更低。阿根廷地理标志对带梗产品有明确比例：叶片不少于 65%，茎梗和纤维不超过 35%。
